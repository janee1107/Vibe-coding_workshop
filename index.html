PROMPT

# Role ＆ Style
你是一個資深的前端網頁設計師。請幫我做一個『2026 MediaTek 年度活動行事曆』網頁，風格要是簡約白色、毛玻璃的高級感。

# Requirement
我需要兩個月份的卡片：
- 3月：健康演講、桌球促進、Global Volunteer Hero
- 4月：捐血活動、植樹體驗、財務管理講座
每項活動要有介紹、報名 deadline，及顯眼的『報名平台』按鈕。

# Constraint (Don't hallucinate)
注意！請不要自己發明假資料，完全依照我提供的文字。按鈕的超連結請先設定成 '#'。

5 分鐘自己做一個小工具

以「會議計時器」為例，感受指令下得「簡單」與「具體」的魔法差異。

簡易版

Basic Prompt

1 Role 角色設定
資深 UI 設計師。

2 Style 風格指定
插畫風格。

3 Requirement 明確需求
做一個會議計時小工具，每 10 分鐘跳出一個提醒；總長不能超過 30 分鐘。

4 Constraint 邊界限制
給我單一 HTML 檔案。

進階版

Advanced Prompt

點擊展示具體化指令

1 Role 角色設定
你現在是一位「資深 UI/UX 設計師」與「前端開發專家」。

2 Style 風格指定
現代簡約的插畫風格，配色請使用柔和的莫蘭迪色系（不刺眼），具備高級質感與流暢的微動畫轉場。

3 Requirement 明確需求
製作一個「會議計時器」，總時長限制為 30 分鐘。包含環形進度條、大字體倒數顯示，以及「開始/暫停/重置」按鈕。
重點功能：每經過 10 分鐘，畫面中央必須彈出醒目的「插畫圖示（例如 ☕️ 喝口水、🧘 伸展一下）」與幽默的提示文字，並帶有溫和的彈出動畫，停留 5 秒後自動消失。

4 Constraint 邊界限制
所有 CSS 與 JS 必須寫在同一個 HTML 檔案中。插畫請使用高畫質 SVG 或 Emoji 實作，嚴禁使用外部圖片連結。確保介面完美響應式（RWD）。

Reality Check：邊界在哪裡？

了解工具的極限，才是聰明的使用者。

✓

Sweet Spot

  • ✦ 單純的精美資訊網站
  • ✦ 活動佈告欄與報名入口 (如行事曆)
  • ✦ 內部團隊的小型投票、抽籤工具
  • ✦ 快速驗證點子的「高擬真草圖」
✗

Danger Zone

  • ✦ 複雜的單一登入 (SSO) 權限控管
  • ✦ 牽涉公司機密人事資料庫的即時串接
  • ✦ 處理大量高頻發的交易系統
  • ✦ 幻想它能完美取代 IT 基礎建設
💡 Guidance：把這把魔法棒當作「精美 UI 產生器」與「靈感實體化工具」，複雜的後端還是交給專業 IT 吧！

撞牆期實錄與解方

會踩坑是正常的，重點是怎麼爬出來。

鬼打牆

"無限迴圈的修 Bug 地獄"

改了 A，結果 B 壞了。你好不容易把 B 修好，結果畫面變空白。AI 只是一直道歉。
解方

果斷放棄！回到上一個會動的版本 (Ctrl+Z 或跟 AI 說「復原」)，然後把你的問題切得更小再重新問。

詞窮

"通靈失敗的詠唱者"

你說「按鈕閃閃發光」，結果它給你土氣跑馬燈。你不知道怎麼形容那種 Apple 的高級感。
解方

直接用截圖溝通！找一張你覺得很棒的網頁截圖貼給 AI，並附註：「請完全模仿這種風格與質感的設計」。

牽一髮動全身

"被貪心反噬的架構"

原本只是投票機，你突然又要登入、權限控管、匯出 Excel。一次丟太多，AI 直接崩潰。
解方

落實「MVP 最小可行性產品」法則。一次只開一個小需求，確定頁面會動了，再去加下一個功能。
